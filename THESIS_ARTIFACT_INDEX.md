# Thesis artifact index

This is the examiner navigation layer. It links each thesis-facing result family to a narrow, auditable artifact chain: implementation → frozen config/prompt → final result → per-question evidence → manifest/checksum.

The submitted thesis determines which result/version was reported. Frozen artifacts determine what each preserved run contains. If the two disagree, record the discrepancy explicitly; never alter, reinterpret, or suppress frozen facts to match the thesis. Unverified thesis-location bindings below do not downgrade the formal status of an experiment.

Use the [English reading guide](docs/ENGLISH_READING_GUIDE.md) for all protected multilingual reports and the complete preservation inventory. English summaries are presentation aids; frozen originals retain their experimental identity.
