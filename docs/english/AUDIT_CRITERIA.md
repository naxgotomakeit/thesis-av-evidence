# Frozen evidence-support criteria

English presentation summary, not a replacement experimental record. The linked frozen originals remain authoritative for byte-level provenance. Numerical values and artifact identities reproduced here are copied without alteration; this summary does not introduce new results or revise frozen labels. See the [source register](../ENGLISH_READING_GUIDE.md) for original-file hashes and checksum membership.

This English summary covers the three protected copies listed in the [source register](../ENGLISH_READING_GUIDE.md). Identical criteria do not imply a shared audit population.

The original protocol describes a Codex-assisted batch audit, not human review and not an independent reviewer-model call at that stage. Method labels, gold, correctness and earlier results were hidden during review. Direct map structure could reveal the method, so full blinding is not claimed.

| Label | Meaning |
|---|---|
| `supported` | The actual supplied input contains explicit evidence that distinguishes the selected option. |
| `partially_supported` | Relevant clues exist, but a decisive part of the judgment lacks evidence. |
| `unsupported` | The supplied input does not support the selected option. |
| `contradicted` | The supplied input explicitly contradicts the selected option. |
| `unreviewable` | Images cannot be inspected, the evidence package is damaged, or verification cannot be completed. |
| `no_final_answer` | The route has no final answer. |

Reason-grounding labels allow multiple assignments: `corresponds_to_input`, `reasonable_unverified_inference`, `common_sense_option_wording_or_guess`, `unsupported_factual_assertion`, `contradicts_input`, and `input_evidence_cannot_verify_claim`.

Review the images actually transmitted. Model reasoning, filenames and aggregate reports alone are insufficient. For Direct, inspect the actual map, images observed by the final answer and tool feedback. Evidence-source labels are `map`, `images`, `map_and_images` or `none`; map-only support is not independently confirmed visual support.

Duration, frequency, ordering and whole-video absence claims require corresponding temporal coverage. More sampled frames do not prove longer duration; an event missing from sampled frames is not proven absent from the video. Record unverifiable claims as such without asserting real-world absence.

Each review records a short rationale, traceable evidence references, missing evidence, confidence and further-review flags. Labels do not modify predictions or official accuracy. ABD and historical R1/R3/GenS use separate E0001–E0900 namespaces. Semantic re-review requires the source media, unlike recomputing statistics from frozen labels.
