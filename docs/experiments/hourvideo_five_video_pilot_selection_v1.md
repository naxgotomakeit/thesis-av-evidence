# HourVideo five-video pilot selection v1

This no-API experiment freezes five content-aligned engineering-pilot videos. Selection uses only question text, task, scenario metadata, duration, audio availability, frame readiness, and option modality. Correct labels, reference timestamps, benchmark canaries, and option content are excluded from selection.

The initial paid scope is one predeclared text-option question per selected video. All other questions on the selected videos remain held out. Expanding that scope after observing results requires a new versioned manifest.

HourVideo dev50 does not expose an explicit theft, robbery, fight, or physical-conflict question. The pilot therefore covers the closest honest categories: global event summary, interpersonal collaboration, multi-phase duration, object-centered activity, cross-location navigation, and one no-audio control. This is not a representative dataset sample and cannot support dataset-level performance claims.
