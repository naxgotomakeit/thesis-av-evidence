# R1_AV / R3_2 cached full-pipeline engineering freeze v1

This no-API experiment creates immutable hash-addressed manifests for the
current R1_AV and R3_2 engineering pipelines. It freezes representation,
map/Planner, retrieval/Fine localization, requirement-centric Sufficiency,
question-scoped Gate, immutable reviewed-visual cache, resolved handoff and
text-only Final Gemini interfaces.

The snapshot intentionally does not freeze manual answer correctness,
HourVideo performance, or dataset-level generalization.
