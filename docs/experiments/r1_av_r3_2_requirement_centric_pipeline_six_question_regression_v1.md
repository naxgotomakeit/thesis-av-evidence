# R1_AV / R3_2 requirement-centric six-question regression v1

This isolated regression expands the validated two-question canary to the frozen six-question EgoPolice 226 diagnostic set.

It keeps maps as navigation inputs, performs requirement-guided retrieval, separates direct evidence from contextual ASR, and applies the shared V3.2.1 contract.
