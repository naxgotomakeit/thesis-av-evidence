# R1_AV structural plus audio timeline v1

R1_AV is an isolated formatting extension of the frozen R1 structural map. It preserves all five visual structural regions and packages them with the 107 canonical timestamped ASR records as independent nodes in one deterministic chronological timeline.

ASR nodes are not nested beneath visual Medium or Coarse regions, do not change visual boundaries, and do not constitute visual confirmation or physical-event claims. This version does not perform AV semantic fusion and does not run Planner, Retrieval, Sufficiency, or final-answer stages.
