# HourVideo R1_AV / R3_2 ten-video pilot v1

The pilot runs one frozen text-option question on each of ten predeclared videos. It uses dynamic 15-second Fine and 45-second Medium nodes over the existing 1-fps frame caches. Shared source embeddings are reused. R1_AV adds YOLOv8x-OIV7/BoT-SORT structured projection; R3_2 adds local Qwen captions and a global caption+ASR semantic map. Online stages use option-centric requirements and the frozen requirement-bound Fine/Gate/cache/final contract.
