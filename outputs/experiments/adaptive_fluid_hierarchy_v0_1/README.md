# Adaptive fluid hierarchy v0.1

Seven operating-frontier methods are compared on the exact frozen Safe-Merge trees. No Fine boundary, merge order, parent/child link, or topology is changed. Local fluid policies use the prespecified within-video merge-quality rank and local quality-drop thresholds. Medium/Coarse counts are outputs.

The four long EgoPolice videos are primary; ten frozen short-video trees are included only for robustness. No VLM, API, download, question, retrieval, Planner, classifier, audio, QA, or canonical path is used.
