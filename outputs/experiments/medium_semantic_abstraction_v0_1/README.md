# Medium semantic abstraction v0.1

Compares deterministic midpoint (1 frame) with 25/50/75% (3 frames) using one persistent, strictly local Qwen2-VL-2B-Instruct instance across 82 frozen Safe Merge Medium nodes. Fine nodes are not captioned; Coarse summaries use ordered Medium text only. No questions, gold, options, external APIs, or canonical pipeline code are used. Semantic quality requires human review.
